# 🛠️ Oiyres Task Manager v2.0 [Core Engine]

Мощный, легкий и быстрый системный диспетчер задач от **Oiyres Inc.** с хакерским интерфейсом. Программа разработана на Python с использованием библиотеки Tkinter и специально оптимизирована для стабильной работы и быстрой разгрузки системы.

## ✨ Основные возможности
* **Живой мониторинг ресурсов:** В реальном времени показывает нагрузку процессора (ЦП) и объем используемой оперативной памяти (ОЗУ) в мегабайтах и процентах.
* **Потоковая архитектура:** Интерфейс программы никогда не зависает благодаря переносу системных расчетов в фоновые потоки.
* **Умное разделение процессов:** Все задачи автоматически сортируются по 3 вкладкам: *Рабочие процессы*, *Фоновые процессы* и *Системные процессы*.
* **Модуль Killer:** Позволяет принудительно завершить абсолютно любой зависший процесс без ожидания сигналов системы.
* **Мгновенный запуск Win+R:** Отдельная кнопка для моментального открытия системного окна «Выполнить».
* **⚡ Оптимизация ПК:** Очищает компьютер от временного мусора (папка Temp) и выгружает скрытые фоновые приложения-апдейтеры.

## 🚀 Инструкция по установке и запуску

Для работы программы на вашем компьютере должен быть установлен **Python 3**.

### 1. Установка зависимостей
Откройте командную строку (консоль) Windows и установите необходимую библиотеку для работы с процессами:
```bash
pip install psutil
```

### 2. Запуск приложения
Скачайте файл `oiyres_manager.py` и запустите его двойным щелчком мыши или через консоль:
```bash
python oiyres_manager.py
```
