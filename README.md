# 🛠️ Oiyres Task Manager v3.0 [Core Engine]

Добро пожаловать в официальный репозиторий экосистемы управления процессами от **Oiyres Inc.** 

**Oiyres Task Manager** — это мощный, легковесный и быстрый системный диспетчер задач с футуристичным Hi-Tech интерфейсом. Программа спроектирована специально для обеспечения максимального контроля над операционной системой Windows, эффективной разгрузки процессора (ЦП) и оперативной памяти (ОЗУ).

---

## 🐍 Два варианта использования софта

Проект адаптирован как для обычных пользователей, так и для разработчиков:

1. **Исходный скрипт Python (`oiyres.core.py`):** 
   Чистый, открытый исходный код для программистов. Его можно кастомизировать, изучать изнутри и использовать как мощное базовое ядро (Core Engine) для подключения собственных модулей и расширений.
   
2. **Скомпилированный файл (`oiyres.core.exe`):**
   Готовое автономное приложение для Windows в один клик. Не требует установки интерпретатора Python и зависимостей — идеально подходит для быстрой оптимизации ПК.

---

## ✨ Основные возможности ядра

* **Живой мониторинг ресурсов:** Непрерывный вывод актуальной информации о загрузке ЦП и объеме занятой оперативной памяти в мегабайтах и процентах на верхней панели.
* **Асинхронная потоковая архитектура:** Системные вычисления перенесены в фоновые потоки, благодаря чему графический интерфейс программы никогда не зависает и работает плавно даже под высокой нагрузкой.
* **Категоризация процессов:** Все активные задачи в системе автоматически сканируются и распределяются по 3 независимым вкладкам:
  * 🖥️ *Рабочие процессы* (пользовательский софт и тяжелые игры).
  * ⚙️ *Фоновые процессы* (скрытые фоновые службы и службы приложений).
  * 🛡️ *Системные процессы* (важнейшие низкоуровневые задачи Windows).
* **Мощный модуль Киллер (Kill):** Позволяет принудительно уничтожить любой зависший или скрытый процесс напрямую через память (метод `proc.kill()`), игнорируя стандартные сигналы Windows.
* **Мгновенный запуск Win+R:** Вызов оригинального диалогового окна Windows «Выполнить» без задержек.
* **⚡ Модуль Оптимизации ПК:** Очищает жесткий диск от скрытого мусора из системной папки `Temp` и завершает ненужные фоновые процессы (апдейтеры, телеметрию), возвращая компьютеру былую скорость.

## 🚀 Инструкция по установке и запуску (для Python-скрипта)

Если вы хотите запустить проект напрямую через исходный код, вам понадобится **Python 3**.

### 1. Установка зависимостей
Откройте консоль (командную строку) Windows и установите главный модуль для работы с процессами:
```bash
pip install psutil
```

### 2. Запуск ядра
Скачайте скрипт `oiyres.core.py` и запустите его командой:
```bash
python oiyres.core.py
```
